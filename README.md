# IT-Helpdesk-Management-ServiceNow-PDI
A ServiceNow IT Helpdesk project for creating and managing support tickets using Client Scripts, Business Rules, UI Policies, and Notifications.

## Overview
Created a custom IT Helpdesk system to create and manage support tickets.
The project includes basic ticket fields and automation to control ticket behavior, form visibility, and email notifications.

### ServiceNow Concepts & Implementation

#### Custom Table
Created a custom IT Helpdesk table with fields such as Caller, Category, Priority, Impact, Urgency, Assignment Group, and State.

#### Client Scripts
Used Client Scripts to control ticket behavior and set priority values.

#### Business Rule
Used a Business Rule to automatically store the current date and time in the SLA date field.

#### UI Policies
Used UI Policies to control field visibility based on the selected Category.

#### Form Design
Configured the Helpdesk form layout using Form Design.

#### Notifications
Configured email notifications for ticket assignment and resolution.
